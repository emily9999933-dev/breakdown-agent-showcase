爆款拆解 Agent

当收到素材审阅台中「已选」状态的素材时，自动完成拆解前筛选、标题与正文拆解、互动数据解读、爆点归因、可复用模板提取与质量校验，输出到「拆解结果」表与本地模板库。

试试模拟体验 查看能力与规范

能力模块

把「已选素材」变成可复用的爆款认知资产：这篇为什么有效、这套怎么复用。

1前置筛选

书名缺失、收藏<50、评论<10、互动综合低 → 跳过并记录原因（评论权重最高）。

2标题拆解

钩子优先级：悬念 → 痛点 → 数字；多钩子都记、标主钩子；关键词 3-5 个；情绪看词与标点。

3正文拆解

按「开头 → 结论 → 中间」：开头钩子、结构类型、结尾引导（下单/互动）、卖点。

4互动数据解读

占比定性：转发 ≥50% 实用型、评论 ≥50% 争议型、否则按点赞 → 共鸣/混合。

5爆点归因

三方向（标题钩子 / 内容实用 / 选题人群）看证据，主驱动 = 证据最明显者，归因带证据。

6模板提取

标题公式（可替换槽位）+ 正文结构模板（4-6 步步骤链），换新主题能直接套用。

7质量校验

回看原文核对：钩子可回溯、结构可还原；不过自动修正重试 1 次，仍不过标「需复核」。

8输出与联动

写入拆解结果（整段 + 结构化字段）、素材状态联动「已拆解」、本地模板库去重追加。

完整判断分支与人工兜底（红色节点 = 必须暂停交给人）。

输入 / 输出 / 成功标准

运行规范，来自最终确认版岗位卡。

输入

  • 素材审阅台「已选」素材：标题、正文、互动数据（赞/评/转/收藏）、链接

输出

  • 拆解结果表：整段拆解 + 结构化字段（钩子/结构/归因/模板等）
  • 本地模板库（供创作 Agent 复用）
  • 素材状态联动「已选 → 已拆解」

成功标准

  • 拆解可追溯、钩子可回溯原文、结构可还原
  • 模板换新主题可产出样稿
  • 归因与互动信号不矛盾、字段完整

能力边界与人工兜底

清晰界定做什么、不做什么、何时交给人。

本期不做

  • 不洗稿、不改写文案（归创作 Agent）
  • 不生成完整脚本 / 成片（归创作 / 制作 Agent）
  • 不判断素材能不能用（判断权在人工审阅台）
  • 不发布、不挂商品链接（归发布 / 选品 Agent）
  • 不碰选品 / 版权判定、不做周报趋势分析

必须暂停交给人确认

  • 素材本身有问题（正文缺失 / 标题正文无关 / 前置筛选不过）
  • 校验不过或归因证据不足 → 标「需复核」
  • 模板质量存疑 → 人工确认是否可用
  • 连续失败率 >20% → 暂停并提醒人工
